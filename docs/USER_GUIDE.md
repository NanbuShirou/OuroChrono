# OuroChrono 使用說明

## 1. 安裝

1. 下載 GitHub Release 中的簽署版 APK。
2. 在 Android 開啟允許安裝未知來源 App 的權限。
3. 安裝 APK 並開啟 OuroChrono。

## 2. Device Code 登入

1. 按「使用 ChatGPT 帳號登入」。
2. App 會顯示並自動複製一次性代碼。
3. 瀏覽器會開啟 OpenAI Codex Device Code 頁面。
4. 登入 ChatGPT 帳號並輸入／確認代碼。
5. 返回 OuroChrono，App 會繼續檢查登入結果。

若 OpenAI 顯示未啟用 Device Code 授權，請在 ChatGPT 的安全性設定中開啟相關選項後重試。

## 3. 主畫面

登入後，主畫面上方提供三個頁簽：

- **用量檢視**：顯示帳號與方案資訊、每週與 5 小時剩餘用量、已使用比例、重置倒數、可用重置次數、最後成功更新時間與立即更新按鈕。
- **通知設定**：設定自動更新週期、用量恢復通知、通知音效與震動，並可發送測試通知或開啟 Android 系統通知設定。
- **系統設定**：登出 ChatGPT 或清除本機資料。

主畫面會依手機的深色／淺色模式自動切換。

## 4. 自動更新

可選更新週期：

- 5 分鐘
- 10 分鐘
- 15 分鐘
- 30 分鐘
- 60 分鐘

Android 可能因 Doze、省電模式、網路狀況或廠牌背景限制延後實際更新。這是系統排程限制，不代表倒數本身是高精度計時器。

## 5. 通知

「用量恢復通知」會在每週或 5 小時用量從低於 100% 恢復到 100% 時發送一次。

可設定：

- 啟用／停用通知。
- 通知音效。
- 震動。
- 發送測試通知。
- 開啟 Android 通知頻道設定。

Android 13 以上必須授予通知權限。手機靜音、勿擾模式與系統通知頻道仍會影響實際聲音與震動。

## 6. 加入桌面小工具

1. 長按 Android 桌面空白處。
2. 選擇「小工具」。
3. 找到 OuroChrono。
4. 將「OuroChrono 用量」拖曳到桌面。
5. 建議保留 4×2 格空間。

Widget 四格內容：

```text
┌──────────────────────────────┐
│  每週剩餘用量   5 小時剩餘用量 │
│       圓環           圓環     │
├──────────────────────────────┤
│    重置次數       更新倒數     │
└──────────────────────────────┘
```

右下角倒數區整格可點擊，點擊後會立即要求更新。

## 7. 圓環解讀

- 中央百分比是剩餘用量。
- 有色圓弧長度也是剩餘比例。
- 顏色依已使用比例判斷，因此剩餘 35% 代表已使用 65%，會顯示黃色。
- `--` 表示 API 沒有提供可辨識資料。

重置次數：

- 0 次：`🤍🤍🤍`
- 1 次：`♥️🤍🤍`
- 2 次：`♥️♥️🤍`
- 3 次：`♥️♥️♥️`
- 4 次以上：`♥️×N`

## 8. 精準倒數權限

Android 12 以上可能要求「鬧鐘與提醒」權限。此權限用於在 Widget 倒數到 `00:00` 時立即切換到下一次倒數，避免顯示 `-00:01`。

未授權時 App 仍可更新，但倒數切換可能被系統延後。

## 9. 登出與清除資料

- 「登出 ChatGPT」會嘗試撤銷 Refresh Token，並清除本機 Token、快取與排程。
- 「清除本機資料」只重置這支手機的登入、快取與排程，不呼叫 OpenAI 撤銷端點。
- App 不保存 ChatGPT 密碼。
